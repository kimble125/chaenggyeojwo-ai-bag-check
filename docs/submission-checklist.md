# 제출 점검표

## 기획안 (A4 2쪽 이내, PDF 권장)
- [ ] 참가 정보: 팀명 잘챙겼조, 구성원
- [ ] 문제 정의: 누가 어떤 불편을 겪는지
- [ ] 서비스 개요: 서비스명, 목적, 기대 효과
- [ ] 서비스 활용 방식: 사용자가 쓰는 순서
- [ ] AI 활용 계획: 쓰는 AI·도구와 각각의 역할
- [ ] 핵심 기능 최대 3가지
- [ ] 차별점: 기존 서비스·범용 AI와 견준 것
- [ ] 역할 분담
- [ ] 생성형 AI 활용 범위를 밝힘

## PoC
- [ ] 파일이면 1GB 이하, 링크면 URL 하나
- [ ] 링크는 로그인 없이 열리거나 더미 계정을 같이 냄. 심사자 열람 권한 확인
- [ ] 대표 입력 3개가 끝까지 도는 것을 다른 기기에서 확인
- [ ] 심사 기간(–12/10)에 주소와 API 키·잔액을 누가 유지하는지 정함

## 공통
- [ ] API 키·비밀번호·개인정보·실제 신분증 사진 없음
- [ ] 첨부가 열리는지 확인
- [ ] 대표자(호연)가 '기획안 제출'과 'PoC 제출'에 각각 올리고 두 항목의 상태 확인
- [ ] 제출 뒤 수정 불가이므로 올리기 전에 둘이 한 번씩 읽음
- [ ] 참가증 신청(원하는 사람 각자)
