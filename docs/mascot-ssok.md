# 쏙이: 가방쏙의 가방 친구 (마스코트 카드)

> 2026-11-20 초안. 지금은 화면을 안내하는 마스코트이고, 대화형 도우미(챙김 메이트)는 기본 기능 뒤의 추가 기능이다.

## 누구

- 이름: 쏙이. 가방에 "쏙" 넣는다는 서비스 이름에서 옴
- 모습: 작고 둥근 보라색 책가방. 크림색 앞주머니와 노란 버클, 짧은 팔다리, 큰 눈. 윗덮개가 살짝 열려 있음(물건이 쏙 들어가는 자리)
- 색: 보라 `#7c5cff`, 크림 `#fff6e9`, 노랑 `#ffd76a`, 테두리 `#23263a` (아이 화면의 색과 같음)
- 그림 파일: `poc/donghyun/app/static/mascot/` 의 `ssok_hello.png`(인사), `ssok_star.png`(다 챙겼을 때), `ssok_look.png`(살펴볼 때), `ssok_no.png`(두고 가자)
- 만든 방법: 이미지 생성 AI로 한 번에 네 표정을 그리고(2026-11-20), 배경을 지워 잘랐음. 제출물에 AI로 만든 그림이라고 밝힘
- 실제 사람이나 기존 작품의 캐릭터를 본뜨지 않음

## 성격과 말투

- 아이 편에서 같이 챙기는 친구. 시키지 않고 "같이 하자"고 말함
- 짧은 반말, 한 번에 한 가지. 예: "6개를 펼쳐 놓자", "이건 두고 가자", "하나만 더 보자"
- 틀렸을 때 탓하지 않음. 못 찾은 것은 "엄마랑 같이 찾아보자", 두고 온 것은 "내일 학교에서 찾아보자"
- 금지는 단호하지만 다정하게, 까닭(통신문 문장)을 같이 보여 줌
- 칭찬은 결과보다 스스로 한 것에: "스스로 챙겨서 멋져"

## 지금 화면에서 하는 일

- 아이 화면 머리마다 표정이 바뀜: 인사(펼치기), 살펴보기(추천, 하나씩, 사진 보는 중), 두고 가자(금지물), 별(다 챙겼지, 스티커판)
- 부모 화면과 프로토타입 첫 화면의 얼굴
- 쏙이의 말은 모두 코드에 적어 둔 문장이다. AI가 지어내는 말이 아니다

## 나중에(대화형 도우미로 키울 때) 지킬 것

- 숫자와 판정(몇 개 남았나, 다 챙겼나, 무엇이 금지인가)은 코드가 정하고 쏙이는 말투만 입힘
- 아이가 AI와 자유롭게 대화하는 기능은 보호자 동의, 나이에 맞는 안전장치, AI라는 고지를 갖춘 뒤에만
- 약, 건강, 개인 사정에 대한 판단은 하지 않고 보호자에게 넘김
- 보상으로 붙잡지 않음(연속 기록, 코인 같은 것은 넣지 않음). 칭찬은 엄마가 주는 스티커가 중심
