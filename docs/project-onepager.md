| 상황 1개 | 집을 나서기 직전, 안내문은 받았지만 다시 읽을 시간이 없음 | 잠정 |

## 아직 안 한 것
- 범용 AI와의 비교 시험(같은 안내문·사진). 주제 확정 전에 한 번 돌린다.
- 시험용 사진·안내문 모으기(`eval/README.md`).
- 이름 확인: '챙겨', '챙겨요' 같은 비슷한 이름의 서비스·저장소가 이미 있다(2026-11-15 GitHub 검색). 기획안의 차별점을 쓸 때 겹치는 서비스를 확인한다.
