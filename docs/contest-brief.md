## 2. 제출물
- **기획안**: A4 2쪽 이내. HWP·HWPX, DOCX, PDF 중 하나. (FAQ와 11/12 메일에는 PPTX도 있으나 11/14 메일에는 없음 → PDF로 내는 것이 안전)
  - 넣을 것 8가지: 참가 정보(팀명·구성원) / 문제 정의 / 서비스 개요(서비스명·목적·기대 효과) / 서비스 활용 방식 / AI 활용 계획(쓰는 AI·도구와 역할) / 핵심 기능 최대 3가지 / 차별점 / 역할 분담
  - 주최 측 샘플 양식(필수 아님, 참고용): `plan/elice_plan_template_sample.pptx`. 표지에 팀명·구성원과 참가 부문(성인)을 적으라고 안내됨. PPTX로 쓰면 PDF로 바꿔 냄.
- **PoC 결과물**: 자유 형식(PPT, 화면 설계안, 프로토타입, Figma, 웹 등). 파일은 1GB 이하, URL은 하나만.
  - 실제로 작동하는 구현은 필수가 아니고, 형식·구현 여부에 따른 불이익은 없다고 안내됨.
  - 채널톡 답: 클릭형 프로토타입만 내도 됨 / 로그인이 필요하면 더미 계정을 같이 냄 / 외부 AI API 호출 가능, 키는 제출물에 넣지 않음.
- 생성형 AI 활용 여부와 범위를 기획안 또는 PoC에 밝혀야 한다.
- 제출 뒤 수정·재제출 불가.

## 3. 제출 방법
1. 대표자가 엘리스 계정으로 로그인 (가입: https://ai-challenge.elice.io/lxp )
2. 탐색 → '엘리스 AI 챌린지' → 단원 목록 '결과물 제출'
3. '기획안 제출'과 'PoC 제출'에 각각 올림 → 두 항목의 제출 상태 확인

- 제출 페이지: https://ai-challenge.elice.io/courses/792783/lectures/all
- 링크로 낼 때는 심사자가 열 수 있게 공유 권한을 연다.

## 4. 심사
- **플랫폼 과목 화면과 11/14 메일(둘이 같음, 더 최근)**: 문제 해결 아이디어 / AI 활용의 적절성 / **기획의 구체성**(주요 기능과 이용 과정이 구체적인가) / 실제 활용 가능성
- 공개 홈페이지(옛 표현으로 보임): 문제 정의의 적합성 / AI 활용의 적절성 / 서비스 구현 완성도 / 실제 활용 가능성
- 두 곳이 다르므로 기획안은 '기획의 구체성'에 맞춰 쓰고, PoC는 핵심 장면이 실제로 도는 것을 보여 준다. 어느 쪽이 최종인지는 주최 측에 묻지 않았다.
- 배점 비공개. 발표 없이 제출물로 심사. 성인 부문 수상 2팀.

## 5. 혜택·시상
- 참가자: 헬피챗(Helpy Chat) 500만 토큰(가입한 사람마다, API 호출 불가), 바이브 코딩 교육 콘텐츠
- 수상: NIA 원장상, 헬피코드 크레딧 약 100만 원 상당, 희망 시 고도화 지원. 현금 시상 없음(채널톡 답).
- 참가증(이수증): 결과물을 낸 참가자가 각자 신청. 신청 기간 11/14–11/30. 조건은 본인 이름 가입 + '엘리스 챌린지' 과목 수강 + 설문 https://eli.so/elice_AI_challenge_certificate . 계정에 등록된 이름으로 발급됨.
