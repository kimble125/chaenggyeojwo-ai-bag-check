# 기획안 (A4 2쪽 이내)

원고는 `plan/proposal.md`에 쓰고 PDF로 낸다. 넣을 것은 주최 측이 정한 8가지다.

1. 참가 정보: 팀명 잘챙겼조 / 구성원
2. 문제 정의: 해결하고 싶은 문제와 그 문제를 겪는 사람
3. 서비스 개요: 서비스명, 제작 목적, 기대 효과
4. 서비스 활용 방식: 사용자가 쓰는 과정
5. AI 활용 계획: 쓰는 AI·도구와 각각의 역할
6. 핵심 기능: 최대 3가지
7. 차별점: 기존 서비스와 견준 특징
8. 역할 분담

끝에 한 줄: 생성형 AI를 어디에 썼는지.

## 주최 측 샘플 양식

`plan/elice_plan_template_sample.pptx` (엘리스 플랫폼 '[샘플] 기획안 양식'에서 받음, 필수 아님). 한 장에 아래 칸이 있다.

팀명 / 팀 구성원 / 해결하고 싶은 문제 / 문제를 겪는 사람 / 제작할 AI 서비스명 / 서비스 제작 목적 / 서비스 기대 효과 / 서비스 활용 방식 / 제작에 활용할 AI·도구 / 핵심 기능(3가지) / 다른 서비스와의 차별점 / 역할 분담

표지에 참가 부문(성인)도 적는다.
